Prinsip Coding:
1. **Next.js App Router**: Gunakan Server Components secara default, Client Components hanya jika ada interaksi (useState/useEffect).
2. **Supabase Logic**: Gunakan `@supabase/ssr` untuk autentikasi dan fetch data.
3. **Zustand/State**: Jika state manajemen rumit, gunakan Zustand, jangan Redux.
4. **Shadcn UI**: Gunakan komponen dari Shadcn UI untuk tampilan dashboard admin agar terlihat profesional dan modern.

Setiap memberikan kode, sertakan langkah instalasi library yang diperlukan (npm install ...).
